This repository contains all data and code associated with the study:

Moraïs et al. (2024), Cryptic diversity of cellulose-degrading gut bacteria in industrialized humans, Science 383(6688): eadj9223.

Publication: Science article (DOI: 10.1126/science.adj9223)

Repository Contents
All data and code from Moraïs et al. (2024) are provided for the evolutionary analyses of the metagenome-assembled genomes (MAGs) described in the study. Specifically, this repository includes:

All analyses performed on the 315 orthologous groups shared among human, rumen, and non-human primate (NHP) genomes.

All analyses performed on the 197 orthologous groups that include orthologous proteins from Clostridium thermobutyricum DSM 4928, used as an outgroup for evolutionary reconstruction.

DNA sequences for the 30 selected MAGs analyzed in the study.

Genome annotations generated using Prokka for the 30 selected MAGs.

For a detailed description of the datasets, methods, and evolutionary analyses, please refer to the associated publication.
